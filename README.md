# Bamse – mitt samlarregister

## Innehåll
- `index.html` – själva samlarregistret.
- `covers/` – fyra medföljande AI-genererade exempelillustrationer som visas direkt i registret när ett nummer saknar egen bild.

## Viktigt om bilderna
AI-bilderna är generella, återkommande exempelillustrationer. De är **inte** de verkliga omslagen till de tidningar som visas och ska inte användas som bevis för hur ett visst nummer ser ut. När du har ett eget foto eller en originalbild som du har rätt att använda kan du lägga in den via **Redigera**. Då ersätter den exempelbilden för just det numret.

Originalomslag kan vara upphovsrättsskyddade. Kontrollera tillstånd och användningsvillkor innan du publicerar dem på en offentlig GitHub Pages-sida.

## Publicera på GitHub Pages
1. Packa upp ZIP-filen.
2. Ladda upp `index.html` och hela mappen `covers` till roten i ditt repository `bamse-samlarregister`.
3. Välj att ersätta den gamla `index.html` och lägg till mappen `covers` med alla fyra `.webp`-filerna.
4. Vänta tills GitHub Pages har publicerat ändringarna och öppna webbplatsen igen.

## Lagring
Registeruppgifterna sparas i webbläsarens lokala lagring. Exportera regelbundet en JSON-säkerhetskopia. Bilder du laddar upp manuellt lagras också i webbläsarens lokala lagring; många stora foton kan därför nå webbläsarens lagringsgräns. De medföljande AI-exempelbilderna ligger däremot som vanliga filer i `covers/`.

## Antal nummer
Årsantalet i startregistret är preliminära uppskattningar och behöver verifieras mot en komplett bibliografisk katalog innan statistiken kan betraktas som en säker total över alla utgivna nummer.
