# Bamse – mitt samlarregister

## Nyheter i denna version
- **Markera alla som ägda** för vald årgång. Funktionen frågar innan alla nummer markeras.
- **Avmarkera alla** för vald årgång, utan att radera anteckningar, skick eller omslagsbilder.
- Ny flik **Lista: har och saknar** som visar nummer du äger respektive saknar, grupperat per år.
- Listan kan filtreras till endast ägda eller endast saknade nummer och skrivas ut.
- Tidigare lokala uppgifter bevaras genom samma lagringsnyckel (`bamse-samlarregister-v1`).

## Installera
Ersätt `index.html` i GitHub-repot med filen i denna ZIP och behåll `README.md` om du vill.

## Viktigt om datan
Årtalen 1973–1998 är markerade som kontrollerade i den här versionen. 1999–2026 är fortfarande preliminära och behöver verifieras mot katalog innan registret kan betraktas som komplett. Appen använder lokal lagring i webbläsaren. Exportera regelbundet en JSON-säkerhetskopia.


Omslagsbilder: mappen `covers/` innehåller unika dekorativa SVG-illustrationer för nummerplatserna. De är platshållare, inte verifierade eller officiella Bamse-omslag. Bilden kan ersättas med eget foto eller bild som får användas.
